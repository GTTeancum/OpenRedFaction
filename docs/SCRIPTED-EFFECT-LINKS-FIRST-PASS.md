# Scripted effect links, first pass

The reconstructed event dispatcher previously returned from several effect callbacks before delivering their outgoing authored links. It now dispatches links, in stored order, after the callback for `Play_Sound`, `Explode`, `Message`, `Music_Start`, `Music_Stop`, `Black_Out_Player`, and `Endgame`. This matches the original-derived generic activation rule for these event classes: the effect is not itself a link-target operation, but its activation can continue a scripted chain. The effect callback still runs once; forwarding does not replay the effect.

A focused dispatcher check covers `Message`→`Explode`→`Play_Sound`, `Music_Start`→`Black_Out_Player`→`Play_Sound`, and the existing staged countdown `Over`→`Play_Sound`→delayed `Endgame` chain. The installed L11S3 authored Message chain, fired from UID 12102, completed a 300-frame PC/Xbox replay and displayed its self-destruct evacuation subtitle in the native 640×480 capture. The stock 64 MiB XEMU guest reported 5,058 available physical pages (19.76 MiB) at the final checkpoint. This verifies real level loading and visible message delivery, but not natural mission traversal or spoken audio output.

L11S3 also exposed a resource admission issue independent of event forwarding. `eos.v3c` has three high-detail skin replacements followed by six separate mip material records. The authored class supplies only the first three replacement names, so the remaining records now retain their model names. The installed level's 128-entity material probe stays within the original 4 MiB NPC texture budget, with a measured 3,598,708-byte peak. Its larger late-campaign weapon loadout requires a 2 MiB weapon image budget; this is an admission limit, not a blanket allocation. Broader crowded-level residency still needs validation.
