# Reciprocal fragment contact with narrow static surfaces

The previous fragment policy swept occupancy spheres and rendered corners. That leaves a vertex/face gap: a small world polygon can intersect the middle of a broad fragment face without touching any sampled sphere or corner. This change adds the reciprocal test, world vertex against moving fragment face, for the static composed collision world. It is an explicit port policy, not a newly claimed original-binary routine.

## Reproducer and math

`fragment_thin_obstacle` in `tests/scene_detached_sources_tests.c` uses a unit-wide box bottom at localY-0.5. Its body center moves fromY1 toY-1 above a0.04-by-0.04 upward-facing patch atY0, centered atX/Z0. Eight radius0.25 grid-sphere samples have coordinates+/-0.25. Each nearest sphere center remains sqrt(0.23^2+0.23^2)=0.32527 units from the finite patch in X/Z, exceeding its radius. All eight actual sphere/face sweeps miss, as do all four fragment-corner rays. Nevertheless the bottom face crosses the patch when1-0.5-2t=0, so the correct contact fraction is0.25.

The reciprocal helper detects all four patch vertices at fraction0.25 with upward response normal and unchanged world contact point. A0.2 fraction limit, an outside point and separating motion reject. A stationary-center60-degree roll also detects face-interior entry during the third angular interval; rotation is not silently treated as translation. The test also runs the world-tree path, verifies source face/room/material, checks parent-room suppression and non-solid face flags, and confirms a material callback failure preserves query outputs. A deliberately undersized proxy bound must not hide the mesh contact.

## Runtime path

Each candidate world vertex is transformed into fragment-local coordinates at five poses spanning four intervals. Triangle fans of the fragment's convex faces use the existing finite thin-face routine to find a crossing. Accepted normals are transformed back from the fragment face and reversed for the moving body's response. Fractional pose acceptance still uses the fragment policy introduced in6468a984. Static face orientation must agree with the response normal.

The scene traverses primary rooms and their children using existing tree scratch, room suppression, source-face identifiers and ordinary0x464 body-face admission. Room, node, face and vertex bounds reject distant candidates. Broad bounds derive from actual mesh vertex lengths, endpoint transforms and a conservative Frobenius-norm bound for normalized intermediate rotations; the original occupancy-sphere radius is not assumed to enclose the mesh. The new path resolves materials through the same runtime-cap/compiled-face metadata adapter as ordinary body collision. It allocates no per-query or retained memory and runs only for active fragment motion.

This supplements the existing sphere/corner path; it does not remove that path, change fragment mass, alter saved schemas or replace the original-derived solid-body scheduler for other callers. Reciprocal mover vertices and edge/edge intersections are not implemented here. Four angular intervals remain an approximation, and the helper is not a complete continuous polyhedron solver. Tight initial overlaps, complex adjacent-face cases and cumulative Xbox cost remain coverage work.
