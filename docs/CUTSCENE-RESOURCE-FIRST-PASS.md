# Campaign cutscene resources and runtime, first pass

The shared PC/Xbox core now owns bounded v180 level sections `0x400` (cameras), `0x4000` (timelines), `0x5000` (control points), and `0x6000` (paths). It decodes the original 16-bit length-prefixed strings, reordered camera basis, descriptor selectors/FOV/hide flag, ordered point durations and words, and four-control cubic paths. Camera and path joins are validated before publication; a failed load leaves the previous owner unchanged. One allocation holds the retained records, while the temporary source sections are charged to the caller's peak budget and released after loading. Source references: [timeline loader research](research/FUTURE-CAMPAIGN-CUTSCENE-TIMELINES-20260915.md) and [camera/path arithmetic](research/FUTURE-CAMPAIGN-CUTSCENE-CAMERA-PATHS-20260915.md).

The installed-level check loads all 12 authored cutscene levels and all 84 timeline points, including L6S3 UID 3696's 14 points, 15 cameras and two paths. Its `pleasework` midpoint samples within 0.0005 of the original-code result. The focused PC check and the NXDK image build pass.

The first runtime pass now dispatches event type 55 into a scene-owned cutscene clock, installs the selected camera, advances authored points and cubic paths, fires each point's linked action, masks player input, and restores normal camera/input when the timeline finishes. Event type 83 receives the completion pulse. L6S3's opening point starts both authored actor animations and its sound chain. Their RFA payloads total 1,085,298 bytes, so the bounded resident-motion ceiling is now 1,280 KiB; this allocates on demand, and the stock-memory XEMU run had 5,139 physical pages (20.07 MiB) available at its endpoint.

L6S3 UID 3696 completed a 300-frame neutral replay on PC and stock 64 MiB XEMU. The inspected native framebuffer shows the authored room and Gryphon and matches the PC frame. This establishes the first live cutscene path, not full sequence parity: camera look-at/FOV, HUD suppression, skip/cancel behavior, other authored sequences, save/load during a cutscene, and full-length actor/action timing still need integration and review.
